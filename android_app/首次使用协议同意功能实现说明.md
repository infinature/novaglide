# 首次使用协议同意功能实现说明

## 功能概述

为NovaGlide Android应用添加了首次使用时的用户协议和隐私政策同意功能。用户在首次打开应用时会先看到精美的启动页面动画，然后再进入协议同意页面。用户必须阅读并同意所有协议才能继续使用，如果不同意则会退出应用。一旦同意后，后续打开应用会显示启动页面动画后直接进入首页，不再显示协议同意页面。

## 核心组件

### 1. 协议同意页面 (`AgreementConsentScreen.kt`)

**位置**: `app/src/main/java/com/sdu/novaglide/ui/features/agreement/AgreementConsentScreen.kt`

**功能特性**:
- **双协议勾选**: 分别需要同意隐私政策和用户服务协议
- **直接链接**: 可点击协议名称跳转到完整协议页面
- **强制同意**: 只有同时勾选两个协议才能继续
- **退出选项**: 提供"不同意并退出"按钮，直接关闭应用
- **美观界面**: 使用Material3设计，支持深色/浅色主题

**UI元素**:
- 应用Logo和品牌信息
- 服务条款说明卡片
- 两个协议同意选项（带状态指示）
- 温馨提示信息
- 底部操作按钮区域

### 2. 协议状态管理器 (`AgreementManager.kt`)

**位置**: `app/src/main/java/com/sdu/novaglide/core/util/AgreementManager.kt`

**核心方法**:
```kotlin
suspend fun isFirstTimeLaunch(): Boolean // 检查是否首次启动
suspend fun hasAcceptedAllAgreements(): Boolean // 检查是否已同意所有协议
suspend fun acceptAllAgreements() // 保存用户同意状态
suspend fun shouldShowAgreementScreen(): Boolean // 判断是否需要显示协议页面
suspend fun resetAgreements() // 重置协议状态（测试用）
```

**数据存储**:
- 使用DataStore持久化存储用户同意状态
- 存储键：`user_agreement_accepted`, `privacy_policy_accepted`, `first_time_launch`
- 独立的数据文件：`agreement_prefs`

### 3. 导航集成

**路由配置** (`AppNavigation.kt`):
```kotlin
const val AGREEMENT_CONSENT = "agreement_consent"
```

**导航逻辑**:
- 协议同意成功 → 跳转到启动页面
- 协议页面链接 → 跳转到对应的协议详情页
- 清理导航栈，防止返回到协议页面

### 4. 应用启动流程 (`MainActivity.kt`)

**启动逻辑**:
1. 初始化依赖（API服务、数据库等）
2. 总是从启动页面开始
3. 启动页面动画播放完成后检查协议状态
4. 根据状态跳转到不同页面：
   - 需要同意协议 → `AGREEMENT_CONSENT`
   - 已同意协议 → `HOME`

**关键代码**:
```kotlin
// MainActivity中总是从启动页开始
determinedStartDestination = AppRoute.SPLASH

// SplashScreen中检查协议状态
LaunchedEffect(Unit) {
    delay(3000)
    val shouldShowAgreement = agreementManager.shouldShowAgreementScreen()
    if (shouldShowAgreement) {
        onAgreementRequired() // 跳转到协议页面
    } else {
        onSplashFinished() // 跳转到首页
    }
}
```

## 用户体验流程

### 首次使用流程
1. **打开应用** → 显示启动页面动画（3秒）
2. **动画结束** → 检查协议状态，跳转到协议同意页面
3. **阅读协议** → 点击链接查看完整协议内容
4. **勾选同意** → 分别勾选隐私政策和用户协议
5. **继续使用** → 点击"同意并继续"进入应用
6. **状态保存** → 系统自动保存同意状态

### 拒绝使用流程
1. **打开应用** → 显示启动页面动画（3秒）
2. **动画结束** → 跳转到协议同意页面
3. **拒绝协议** → 点击"不同意并退出"
4. **应用关闭** → 系统直接退出应用

### 后续使用流程
1. **打开应用** → 显示启动页面动画（3秒）
2. **动画结束** → 检查协议状态，直接进入首页
3. **正常使用** → 无需再次显示协议页面

## 技术实现细节

### 状态管理
- **DataStore**: 用于持久化存储协议同意状态
- **StateFlow**: 响应式状态管理
- **协程**: 异步处理数据读写

### UI设计
- **Material3**: 现代化设计规范
- **动态主题**: 自动适配深色/浅色模式
- **响应式布局**: 适配不同屏幕尺寸
- **无障碍支持**: 完整的ContentDescription

### 导航管理
- **Navigation Compose**: 现代化导航框架
- **路由管理**: 清晰的路由定义和跳转逻辑
- **状态恢复**: 支持配置变更时的状态保持

## 安全考虑

### 数据安全
- 协议同意状态本地存储，不上传到服务器
- 使用DataStore加密存储（如果配置）
- 重置功能仅用于开发测试

### 用户隐私
- 明确告知数据收集和使用方式
- 提供完整的隐私政策和用户协议
- 尊重用户的选择权（可以退出）

该功能完整实现了应用首次使用时的协议同意机制，通过精美的启动页面动画提供良好的首次印象，然后在协议同意页面确保用户在充分了解服务条款和隐私政策的基础上使用应用，符合现代应用的合规要求。整个流程设计兼顾了用户体验和法律合规，为后续功能扩展奠定了坚实的基础。
